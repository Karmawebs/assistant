# Karmi V2 — Karmi Assistant

## Estado
🚧 En desarrollo.

Este documento es la especificación viva de V2. No representa todavía una versión final.

## Objetivo
Convertir Karmi en el asistente inteligente del ecosistema Karma: una presencia mínima en macOS desde la que conversar, recibir avisos y relacionarse con herramientas, agentes y aplicaciones sin convertir Karmi en otra aplicación de gestión.

**Karma App = donde trabajamos.**  
**Karmi = quien nos ayuda a trabajar.**

## Método de desarrollo
1. Añadir nuevas capacidades sobre la rama `karmi-v2`.
2. Probarlas en uso real.
3. Decidir cuáles aportan valor.
4. Eliminar o simplificar lo que no funcione.
5. Mejorar interfaz, interacción y estabilidad.
6. Validar el conjunto.
7. Solo entonces cerrar y lanzar V2.

## Áreas previstas

### ChatGPT / OpenAI
- Chat integrado.
- Integración con OpenAI.
- Selección de modelo cuando resulte útil.
- Contexto y archivos.
- Conversación desde Karmi.

### Voz
- Hablar directamente con Karmi.
- Transcripción.
- Activación rápida.
- Revisión y mejora de Option+K y de la interacción desde el notch.

### Agentes
- Integración con Codex y otros agentes que aporten valor.
- Estado de sesiones.
- Avisos de trabajo terminado.
- Solicitudes de permiso cuando proceda.
- Acceso a la sesión relacionada.

### GitHub
- Integración con los repositorios de Karma.
- Actividad relevante de desarrollo.
- Contexto sobre cambios, commits y trabajo de agentes.
- Avisos útiles relacionados con el ciclo de desarrollo.

### Ecosistema Karma
- Karmi podrá relacionarse con Finance, Work, Care y la aplicación unificada.
- Las apps no se integrarán como navegadores/launchers permanentes dentro de Karmi.
- El objetivo será consultar, actuar o recibir notificaciones cuando tenga sentido.

### Notificaciones
- Centralizar avisos útiles de agentes, GitHub y aplicaciones Karma.
- Mantener la interfaz silenciosa cuando no exista nada relevante.

### Interfaz
- Mantener la identidad negra con ojos blancos de Karmi.
- Evolucionar animaciones, estados y feedback visual.
- Karmi debe permanecer pequeña y discreta en reposo.
- La interfaz ampliada debe aparecer solo cuando exista interacción o información útil.

## Qué no damos por cerrado todavía
V2 se construirá de forma experimental. Ninguna función nueva queda considerada definitiva hasta que haya sido probada y validada. Tampoco se eliminarán funciones de V1 de forma irreversible antes de evaluar su sustitución.

## Rama
Todo el desarrollo de esta generación se realizará inicialmente en `karmi-v2`.


## Base técnica V2 — 2026-10-03

Primera importación selectiva desde la versión moderna de Coucou:

- Arquitectura de proveedores de chat y selector de modelos.
- Base OpenAI / Anthropic / Google AI y proveedores OpenAI-compatible.
- Catálogo central de pills para herramientas, agentes, IA y servicios.
- Arquitectura multi-agente con soporte para Codex y agentes externos.
- Motor de hooks actualizado con permisos, sesiones y estados.
- Endurecimiento del socket y tratamiento de eventos.
- Geometría adaptativa del notch.
- Se conserva la identidad propia de Karmi y el acceso Option+K.
- La pantalla principal deja de actuar como launcher permanente de APP / WORK / CARE y pasa a centrarse en hablar o escribir a Karmi.

### Pendiente de validación
Esta base todavía debe compilarse y probarse localmente en macOS antes de considerarse funcional. Las siguientes iteraciones resolverán incompatibilidades derivadas del port selectivo y adaptarán Settings, pills y notificaciones a la identidad Karmi.
