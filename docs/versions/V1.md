# Karmi V1 — Karmi original

## Estado
Versión funcional anterior al inicio del desarrollo de Karmi V2.

## Origen
Karmi V1 nace a partir del proyecto open-source Coucou y se personaliza para convertirlo en un asistente propio de Karma.

## Identidad visual
- Personaje Karmi con cuerpo negro y ojos blancos.
- Presencia en la parte superior de macOS / notch.
- Interfaz expandible.
- Zona de hover superior reducida para evitar activaciones accidentales.

## Interacción
- Acceso rápido mediante Option+K.
- Interacción desde la zona superior de la pantalla.
- Base de micrófono/transcripción.
- Comportamientos y animaciones heredados de Coucou junto con personalizaciones de Karmi.

## Ecosistema Karma
Durante V1 se exploró el uso de Karmi como punto de acceso a las aplicaciones del ecosistema Karma: Finance, Work y Care.

Este planteamiento queda documentado como parte de V1, pero será revisado en V2. La aplicación unificada de Karma pasa a encargarse de la interfaz de gestión y Karmi evoluciona hacia un rol de asistente.

## Código
La referencia histórica de esta generación es la rama `karma-v1`.

## Cierre de V1
V1 se considera la base desde la que comienza V2. A partir de este punto, los nuevos experimentos y desarrollos se realizarán en `karmi-v2`, manteniendo V1 separada para poder consultar y recuperar su estado.
